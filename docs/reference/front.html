One loop, five moves.

Every Baton session runs the same contract. The demo above plays it live; the war-room lets you drive every step yourself.

01Ask S1

Anyone in the room asks in the feed — the agent answers with retrieval-backed citations.

02Cite S1

03Co-sign S3

Risky actions wait for two distinct humans on the same payload hash. Fail-closed, always.

04Hand off S3

Baton out. Close returns 409 until the successor explicitly ACKs ownership.

05Resume S2

    GLOSSARY

    LogbookThe room's shared memory. Every answer, decision and event is checkpointed into it.
    CheckpointA save point (push_index). Successors resume from the latest one with zero repeat questions.
    Co-signTwo distinct humans must sign the same payload hash before a staged action executes.
    W = 10 minThe signature window. Expire unsigned → the action cancels. Fail-closed.
    409 gateA room with a pending handoff can't be closed until the successor ACKs ownership.
